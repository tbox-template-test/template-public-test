- Fill in `site-platform.json`.
- Fill in Project facts above.
- Confirm staging cannot be indexed.
- Confirm the production canonical origin.
- Confirm the repository's local Standards workflow runs.
- Require the Standards check before merge where GitHub rulesets/branch
  protection are available.
